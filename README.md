

# Hao | Developer Portfolio

A minimalist, responsive portfolio website built to showcase my software engineering projects and technical skills.

## Live Demo

**[https://hao-portfolio.onrender.com]**

## Tech Stack

* **HTML5:** Semantic document structure.
* **CSS3:** Custom styling using **CSS Grid** for layout and **CSS Variables** for the dark navy color theme.
* **Zero Frameworks:** Built with pure, vanilla web technologies for maximum performance and fast loading times.

## Content Overview

The site is divided into three main sections:

1. **Hero:** Introduction and current academic focus at Trinity College Dublin.
2. **Group Projects:** collaborative work including *AI Study Tutor* and the *WebGL Space Shooter*.
3. **Personal Projects:** Individual frontend demos like the *Four Seasons Gardening* landing page and *JS Drum Kit*.

## How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. *Note: No `npm install` or build process is required.*
